**Handshake Protocol – Verilog & Arty FPGA**
**Overview**
Implementation of a Handshake Protocol using Verilog, including a dedicated testbench for functional verification and hardware implementation on the Arty FPGA development board.

**Features**
* Request and acknowledgment signaling
* Reliable data transfer
* Synchronous RTL design
* Verilog testbench verification
* FPGA hardware implementation

**Files**
* `handshakeprotocol.v` – Verilog RTL design
* `tb_handshakeprotocol.v` – Testbench
* `Makefile`
* `flow.json`
* `arty.xdc`
* `handshakeprotocol.bit` 

**Tools & Technologies**
Verilog • Arty FPGA • Vivado • RTL Design • Digital IC Design

**Verification**
The design was verified using a Verilog testbench by analyzing the request, acknowledgment, and data transfer signals through simulation waveforms.

**Result**
The Handshake Protocol was successfully simulated, verified, and implemented on the Arty FPGA board.
